# 🏨 Hotel Management System

## 📖 Overview

Hotel Management System is a web-based application developed using ASP.NET Web Application (.NET Framework) to simplify hotel operations such as customer management, room management, and room booking. The application provides an easy-to-use interface for managing hotel records efficiently while reducing manual work.

The project is developed using C#, ADO.NET, and SQL Server for backend operations, while HTML, CSS, JavaScript, and Bootstrap are used to build a responsive and user-friendly interface.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the solution in Visual Studio.
3. Restore or import the SQL Server database.
4. Update the database connection string in **Web.config**.
5. Build the solution.
6. Run the application using IIS Express.
